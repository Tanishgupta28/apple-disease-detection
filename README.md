# Apple Disease Detection from Apple Leaf Images

Rebuilding an NIT internship project into a reproducible six-class apple leaf classification study.

The nine original notebooks are preserved without changes in `original_work/Apple disease detection codes/`. Their source and stored results are audited in [docs/legacy_experiments.md](docs/legacy_experiments.md). Recovery hashes are recorded in [docs/original_manifest.json](docs/original_manifest.json).

Historical four-class results are not the final six-class benchmark. Dataset preparation, training, evaluation, and the demo are being added; no new metrics have been measured yet.
