# Recovered four-class dataset audit (October 2026)

The original internship notebooks under `original_work/` reference
`/kaggle/input/appledisease/Train` and `/kaggle/input/appledisease/Test`.
This Windows workspace contains matching folders under `apple_disease_classification/`:
382 Train files and 120 Test files. The notebooks' stored 307/75/120 counts sum
to the same 502 files. Matching names/counts support a relationship, but without
an original archive hash we cannot prove byte-for-byte identity to the internship input.

Visual inspection of a sample from every class establishes that these are **fruit
photographs**, not a verified leaf-only dataset. Some have commercial stock-image
watermarks. Original publisher, collection procedure, expert label validation,
and redistribution license are **unverified**. The raw images and derived example
montages stay local and are excluded from Git. Folder labels are inherited annotations,
not newly confirmed biological diagnoses. Do not claim this audit validates the resume's
"3,000+ labelled leaf images" statement. Only 472 distinct decoded images were found.

Public-source investigation found PlantVillage apple data with Scab, Black Rot,
Cedar Rust, Healthy, and the previous repository's AppleLeaf9 six-class experiment.
Neither supplies the identical historical fruit labels. Rust is not Blotch and
leaf black rot is not automatically equivalent to a rotten-fruit label. No such
mapping is applied and augmentation is never counted as additional unique originals.

All 502 decoded; zero corrupt images. SHA-256 byte and decoded-pixel hashes both
found 472 unique images. Exclusions: 30 redundant exact copies, 11 training images
related to original test images, and 2 images in a near-duplicate component with
conflicting labels. There are 96 exact/near pair candidates. Near matches use
64-bit perceptual hashes with Hamming distance <=6 across eight rotations/reflections.
Connected components are conservative: a chain can group images farther apart than 6.
Hash similarity is a screening heuristic; it cannot certify the same leaf/fruit,
source image, orchard, photographer, or acquisition session. Watermarks/backgrounds
can create shortcuts and undiscovered leakage remains possible.

`results/four_class/audit_manifest.csv` contains every decoded file and its disposition.
`near_duplicates.csv` records every candidate pair. `manifest.csv` contains only
included images, relative paths, class index, hashes, group and split membership.
Original Test takes precedence. Related Train files are excluded, never moved into
the test set. Within remaining Train groups, seeded per-class allocation targets
20% validation. A group is indivisible; exact ratios are not guaranteed. All classes
occur in all splits. The train-only class weights use N/(4*n_class).

The test set has historical exposure through internship experimentation. It is held
out from the **new** fits, but is not an independently collected prospective test set.
Do not interpret its score as orchard deployment performance.

## Reproduction

Obtain the original images lawfully and arrange the eight directories above. Then:

```powershell
python -m apple_disease.data --root apple_disease_classification --output results/new_audit
```

Preparation refuses to overwrite a manifest. All models share the same manifest.
Training verifies image hashes before decoding. Resize is bilinear, RGB, EXIF-aware,
96x96; pixels remain [0,255] until model-specific preprocessing. CNN/ResNet augmentation
is inside Keras random layers, active only during training. ANN uses deterministic
texture features and train-adapted normalization. No test data fit the scaler.

Related public sources (not substituted):
- [PlantVillage source listing](https://figshare.com/articles/dataset/PlantVillage_Dataset/26096800)
- [AppleLeaf9 source](https://github.com/JasonYangCode/AppleLeaf9)
- [Fruit-class research example](https://arxiv.org/abs/1412.7277)

The local examples are generated by `python -m apple_disease.examples`; they are
available under `results/local_examples/` and are deliberately not redistributed.
